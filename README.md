# Automated-News-Photo-Card-System

### 📰 অটোমেটেড নিউজ ফটো-কার্ড জেনারেটর (Automated BD News PhotoCard Generator)

শীর্ষস্থানীয় বাংলাদেশি সংবাদ পোর্টাল (প্রথম আলো, গুগল নিউজ বিডি, ডেইলি স্টার ইত্যাদি) থেকে আজকের তাজা খবর স্বয়ংক্রিয়ভাবে সংগ্রহ করে ডায়নামিক কিউআর কোড সহ প্রফেশনাল ফটো-কার্ড তৈরির সম্পূর্ণ স্বয়ংক্রিয় ও ক্লাউড-রেডি সিস্টেম।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **রিয়েলটাইম লাইভ নিউজ সংগ্রহ (News Ingestion Engine)**:
   - গুগল নিউজ (বাংলাদেশ সমগ্র), প্রথম আলো এবং শীর্ষস্থানীয় পোর্টালের RSS ফিড থেকে স্বয়ংক্রিয়ভাবে আজকের সর্বশেষ সংবাদ সংগ্রহ করে।
   - প্রতি খবরের সাথে ওপেনগ্রাফ ইমেজ, ক্যাটাগরি, প্রকাশকাল ও সোর্স লিংক স্বয়ংক্রিয়ভাবে যুক্ত হয়।

2. **১০০% নির্ভুল বাংলা টাইপোগ্রাফি (Pixel-Perfect Bengali Typography)**:
   - ব্রাউজার-লেভেল ক্রোমিয়াম রেন্ডারিং ইঞ্জিন (`puppeteer-core`) ব্যবহারের কারণে কোনো বাংলা যুক্তাক্ষর, হ্রস্ব-ই কার বা রেফ ভাঙে না।
   - `Hind Siliguri` এবং আধুনিক ফন্ট দিয়ে প্রথম আলো বা সময় টিভির মতো দৃষ্টিনন্দন ডিজাইন।

3. **ডায়নামিক কিউআর কোড (Dynamic Scannable QR Code)**:
   - প্রতিটি ফটো কার্ডে মূল নিউজের সরাসরি সোর্স লিংকের হাই-রেজোলিউশন কিউআর কোড জেনারেট হয়।
   - দর্শকরা কার্ড স্ক্যান করেই সরাসরি মূল প্রতিবেদন যাচাই করতে পারেন।

4. **৩টি পেশাদার টেমপ্লেট ডিজাইন (3 Ready-to-Use Templates)**:
   - **Breaking**: ব্রেকিং ও জাতীয় গুরুত্বপূর্ণ খবরের জন্য সিনেমাটিক ডার্ক গ্রেডিয়েন্ট ও বোল্ড শিরোনাম।
   - **Editorial**: বিশেষ প্রতিবেদন ও ম্যাগাজিন স্টাইলিশ ফ্রেম ডিজাইন।
   - **Quote**: বিশিষ্ট ব্যক্তিদের বক্তব্য বা উদ্ধৃতি সম্বলিত আকর্ষণীয় কোটেশন স্টাইল।

5. **স্মার্ট ডুপ্লিকেট প্রতিরোধ (Deduplication Engine)**:
   - একই খবর বারবার যাতে তৈরি না হয়, সেজন্য SHA-256 ইউআরএল ও টাইটেল নরমালাইজেশন ক্যাশ মেমোরি।

6. **এআই হেডলাইন ও সামারি অপ্টিমাইজেশন (Gemini AI Integration)**:
   - ঐচ্ছিক গুগল জেমিনি (Gemini Flash) এআই দিয়ে লম্বা শিরোনামকে ফটো-কার্ডের উপযোগী ২-লাইনের আকর্ষণীয় শিরোনাম ও সারসংক্ষেপে রূপান্তর।

7. **টেলিগ্রাম ব্রডকাস্ট অটোমেশন (Telegram Dispatcher)**:
   - কার্ড তৈরি হওয়ার সাথে সাথে স্বয়ংক্রিয়ভাবে আপনার টেলিগ্রাম চ্যানেল বা গ্রুপে ক্যাপশন সহ ফটো কার্ড পোস্ট করার সুবিধা।

8. **ইন্টারেক্টিভ ওয়েব ড্যাশবোর্ড (Web Studio Dashboard)**:
   - ব্রাউজারে `http://localhost:3000` এ রিয়েলটাইম কার্ড তৈরি, লাইভ নিউজ ব্রাউজ ও প্রিভিউ/ডাউনলোড সুবিধা।

9. **পিসি ছাড়া ২৪/৭ ক্লাউড অটোমেশন (100% PC-Less Cloud Automation)**:
   - **GitHub Actions Workflow** যুক্ত করা আছে, যা কোনো লোকাল পিসি ছাড়াই সম্পূর্ণ ফ্রিতে প্রতি ৩০ মিনিট পর পর ক্লাউডে স্বয়ংক্রিয়ভাবে রান হয়ে কার্ড তৈরি করে।
   - ডকার ও ক্লাউড রান/রেন্ডার ডেপ্লয়মেন্টের জন্য `Dockerfile` এবং `docker-compose.yml` প্রস্তুত।

## 🚀 দ্রুত শুরু করার নির্দেশিকা (Quick Start)

### ১. ডিপেন্ডেন্সি ইনস্টল ও বিল্ড:
```bash
npm install
npm run build
```

### ২. টেস্ট ফটো কার্ড তৈরি করে যাচাই করুন:
```bash
node dist/cli.js test
```
*(এটি চালু করলে `output/` ফোল্ডারে তাৎক্ষণিকভাবে ৩টি ভিন্ন টেমপ্লেটের টেস্ট ফটো-কার্ড তৈরি হবে)*

### ৩. আজকের লাইভ খবর দেখে কার্ড জেনারেট করুন:
```bash
npm run generate
```
*(এটি পোর্টাল থেকে আজকের শীর্ষ খবর ফেচ করে স্বয়ংক্রিয়ভাবে ফটো-কার্ড তৈরি করবে)*

### ৪. ইন্টারঅ্যাক্টিভ ওয়েব স্টুডিও চালু করুন:
```bash
npm run web
```
ব্রাউজারে ভিজিট করুন: **`http://localhost:3000`**

## ⚙️ কনফিগারেশন ফাইল (.env)

প্রজেক্টের মূল ডিরেক্টরিতে `.env` ফাইলটিতে প্রয়োজন অনুযায়ী সেটিংস দিন:

```env
PORT=3000
MAX_CARDS_PER_RUN=3
TEMPLATE_STYLE=breaking       # breaking | editorial | quote
CARD_ASPECT_RATIO=square      # square (1080x1080) | portrait (1080x1350)

# (ঐচ্ছিক) এআই দিয়ে শিরোনাম আকর্ষনীয় করতে:
GEMINI_API_KEY=your_gemini_api_key

# (ঐচ্ছিক) স্বয়ংক্রিয়ভাবে টেলিগ্রাম চ্যানেলে পাঠাতে:
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=@your_channel_or_chat_id
```

## ☁️ পিসি ছাড়া ফুল অটোমেশন চালানোর নিয়ম (Cloud Setup)

১. এই প্রজেক্টটিকে আপনার GitHub রিপোজিটরিতে পুশ করুন:
```bash
git init
git add .
git commit -m "Initial commit of BD News PhotoCard Generator"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

২. আপনার GitHub রিপোজিটরির **Settings > Secrets and variables > Actions** এ যান এবং নিচের সিক্রেটগুলো যোগ করুন:
   - `GEMINI_API_KEY` (ঐচ্ছিক)
   - `TELEGRAM_BOT_TOKEN` (ঐচ্ছিক)
   - `TELEGRAM_CHAT_ID` (ঐচ্ছিক)

৩. `.github/workflows/generate-cards.yml` ফাইলটি ইতিমধ্যে সেটআপ করা আছে।
   - এটি প্রতি ৩০ মিনিট পর পর স্বয়ংক্রিয়ভাবে ক্লাউডে রান হবে।
   - আপনার ল্যাপটপ বা কম্পিউটার সম্পূর্ণ বন্ধ থাকলেও ২৪/৭ নতুন খবর আসলেই কার্ড তৈরি হয়ে আপনার টেলিগ্রাম চ্যানেলে পৌঁছে যাবে এবং গিটহাবে সেভ হবে!
